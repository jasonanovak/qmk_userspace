# jasonanovak_ploopy_classic_tapdance

Keymap for the Ploopy Classic / Classic 2 trackball.

| Button        | Action                                         |
|---------------|------------------------------------------------|
| Thumb bottom  | Left click (button 1)                          |
| Wheel click   | Middle click (button 3)                        |
| Thumb top     | Tap: back (button 4). Double tap: forward (5)  |
| Middle finger | Right click (button 2)                         |
| Ring finger   | Button 6                                       |

Combos (press together):

| Buttons                 | Action   |
|-------------------------|----------|
| Thumb bottom + ring     | Button 7 |
| Middle + ring           | Ctrl+N   |

DPI options are 500 / 750 / 1000 / 1250 / 1500. The default index is 4 (1500),
which suits the Classic 2 sensor. Use index 3 for the original Classic.
